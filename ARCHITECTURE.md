# Larkspur architecture

A short map of how the site is put together, for whoever opens the repo next.

## File tree

- `index.html`, `menu.html`, `story.html`, `events.html`, `journal.html`,
  `journal/*.html`, `field-report.html`, `colophon.html`, `reserve.html`,
  `404.html` — the pages. Hand-authored HTML generated by the `build_*.py`
  scripts from `templates.py`; each script writes one page and can be run
  alone.
- `templates.py` — the shared page shell: head metadata, JSON-LD, navigation,
  footer, back-to-top button. Change the shell here, rebuild everywhere.
- `assets/css/main.css` — the design system in cascade layers: tokens,
  themes (paper / late service), base, typography, layout, components,
  motion, responsive, misc. ~3,000 lines, organized by numbered section
  headers so Ctrl+F "9. Marquee" style lookups work.
- `assets/css/fonts.css` — two @font-face blocks for the self-hosted variable
  fonts (Fraunces display, Inter text).
- `assets/css/menu-print.css` — a print stylesheet for the menu page that
  prints every panel, hides chrome, and appends an address footer line.
- `assets/js/main.js` — theme toggle, header scroll state, reveals, hero
  crossfade and word rise, menu tabs and filters, lightbox, accordions,
  forms, footer bits, marquee seeding.
- `assets/js/search.js` — runtime local index, scoring, full-screen search
  sheet with keyboard navigation, header trigger injection.
- `assets/js/enhance.js` — progressive enhancement: scroll progress, View
  Transitions for internal navigation, anchor focus handling, after-10pm
  dark default, a konami easter egg, service clock.
- `assets/img/*.svg` — generated editorial artwork (risograph-style
  landscapes, table scenes, hearth), written by the generator script.
- `_worker.js` — Cloudflare Pages Functions: security headers + CSP,
  immutable asset caching, SPA-style 404 handling, probe-path blocking.
- `robots.txt`, `sitemap.xml`, `manifest.json`, `llms.txt`, `favicon.svg` —
  the plumbing crawlers and assistants expect.

## The decisions worth keeping

1. **No framework.** The pages are static HTML. Everything interactive is
   progressive enhancement that degrades to a fully readable document.
2. **Tokens all the way down.** Both themes are variable remaps. A new brand
   is a token file change, not a component rewrite.
3. **Layered CSS.** `@layer tokens, base, typography, layout, components,
   motion, responsive, misc` keeps overrides sane and specificity boring.
4. **One observer for entrances.** All reveal animations share a single
   IntersectionObserver with staggered `--reveal-delay` per index.
5. **Search is offline.** The index is ~14 entries scored in the browser; no
   network call, no service, nothing to pay for.
6. **Deploy is a zip.** Cloudflare Pages direct upload; every zip must contain
   `index.html` and `_worker.js` at the root.

## Rebuilding

```
python3 build_home.py && python3 build_menu.py && python3 build_story.py \
  && python3 build_journal.py && python3 build_reserve.py \
  && python3 build_404.py && python3 build_extra.py \
  && python3 build_extra2.py && python3 build_extra3.py \
  && python3 build_styleguide.py
```

The `build_extra*` scripts are additive (extra essays, events page, field
report). They are idempotent: running them twice produces the same files.
